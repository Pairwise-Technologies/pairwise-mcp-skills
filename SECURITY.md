# Security

## Report a vulnerability

Report security issues privately. Do not open a public issue or pull request.

- **Preferred:** use GitHub's private vulnerability reporting: the **Security** tab of this repo, then **Report a vulnerability**.
- **Or email** [support@pairwise.ai](mailto:support@pairwise.ai) with "Security" in the subject.

Include what you found, where, and the steps to reproduce it. Do not include real candidate or customer data.

## Scope

- The content of this repo: connection steps, skills and plugin files.
- The hosted Pairwise MCP server at `https://mcp.pairwise.ai/mcp`.

Only test with your own Pairwise account and your own data. Do not access, change or delete data that belongs to anyone else.
